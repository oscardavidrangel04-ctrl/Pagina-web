# Calculadoras México — Portal SEO

Incluye:
- Página principal real.
- 8 calculadoras.
- 8 artículos.
- Página de calculadoras y página de artículos.
- Acerca de, privacidad, términos, contacto y 404.
- SEO técnico: canonical, Open Graph, Twitter, JSON-LD, breadcrumbs, sitemap y robots.
- Diseño adaptable.
- Redirecciones desde las páginas antiguas de aguinaldo, vacaciones e IVA.

## Cómo probar
Abre esta carpeta completa en VS Code y ejecuta `index.html` con Live Server.

## Antes de publicar
1. Conserva una copia de tu sitio anterior.
2. Prueba todas las calculadoras.
3. Reemplaza el texto temporal de contacto.
4. Sube todos los archivos, incluido `vercel.json`.
