# Calculadoras México — Versión 1.0 Producción

Portal estático de calculadoras y guías para México.

## Incluye
- 26 calculadoras.
- Artículos, categorías e interlinking.
- SEO técnico y datos estructurados.
- Favoritos, historial, impresión y PDF.
- Consentimiento de privacidad.
- Preparación para Analytics y AdSense.
- PWA ligera.
- Configuración para Vercel.

## Publicación
Sube el contenido completo de esta carpeta a Vercel.

## Configuración externa
Edita `assets/js/config.js` únicamente con identificadores reales.

`1.0.0`
