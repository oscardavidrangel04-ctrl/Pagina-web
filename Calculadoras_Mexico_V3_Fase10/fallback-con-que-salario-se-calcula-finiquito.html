¿Con qué salario se calcula el finiquito?

Antes de calcular el finiquito debes identificar el salario correcto y no mezclar salario mensual, diario, neto e integrado como si fueran lo mismo.

Actualizado el 2 de septiembre de 2026 · Guía informativa

En esta guía

  2. Salario diario

Respuesta rápida

Para una estimación sencilla se parte del salario que corresponde a tu relación laboral y se transforma a una base diaria cuando el concepto se calcula por días. Sin embargo, no todos los conceptos del cierre laboral necesariamente usan exactamente la misma base, por lo que conviene revisar cada prestación.

Del salario mensual al salario diario

Si recibes un salario mensual fijo, una aproximación común para herramientas de cálculo es dividir el salario mensual entre 30 para obtener una cuota diaria orientativa. Esa cifra permite estimar días de sueldo pendientes y sirve como punto de partida para otras prestaciones.

No confundas salario bruto con salario neto. El neto ya incorpora descuentos y no es una buena referencia para reconstruir automáticamente todas las prestaciones.

La base puede cambiar según el concepto

La Ley Federal del Trabajo distingue el salario y su integración. Además, las reglas específicas de cada prestación pueden usar referencias distintas. Por eso un cálculo serio separa salario pendiente, aguinaldo, vacaciones, prima vacacional y, cuando aplica, indemnizaciones o prima de antigüedad.

En la calculadora de finiquito de este sitio, el salario mensual se usa como dato de entrada para una estimación orientativa de las partidas incluidas. Si tu remuneración es variable, contiene comisiones o prestaciones especiales, conviene validar la base con recibos de nómina y una fuente oficial.

Ejemplo orientativo

Con un salario mensual de $15,000, la herramienta obtiene una referencia diaria de $500 al dividir entre 30. A partir de ahí calcula los días pendientes y combina las prestaciones capturadas. El resultado no sustituye un cálculo legal individual cuando existen comisiones, bonos, salario variable o condiciones contractuales particulares.

Preguntas frecuentes

¿El finiquito se calcula con sueldo bruto o neto?

Para estimar prestaciones no conviene partir del neto después de descuentos. Debe identificarse el salario base aplicable a cada concepto.

¿Puedo dividir mi sueldo mensual entre 30?

Es una aproximación habitual para obtener una cuota diaria en cálculos simples con salario mensual fijo, pero cada prestación debe revisarse según sus reglas.

¿Qué pasa si mi salario es variable?

Comisiones, bonos u otros componentes pueden cambiar la base aplicable. Revisa recibos y confirma el cálculo si tu remuneración no es fija.
