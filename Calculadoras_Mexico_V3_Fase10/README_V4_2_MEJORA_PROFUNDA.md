# Calculadoras México V4.2 — mejora profunda

Actualización posterior a V4.1 centrada en contenido útil, resultados e interconexión temática. `sitemap.xml` se conserva sin cambios porque ya fue enviado a Search Console.

## Mejoras principales

- Las 50 calculadoras tienen ahora 8 preguntas frecuentes visibles y sincronizadas con FAQPage JSON-LD: 400 FAQ en total.
- Las 10 calculadoras prioritarias (ISR, salario neto, aguinaldo, vacaciones, finiquito, liquidación, IVA, horas extra, prima vacacional y préstamo) incorporan casos para comparar y errores comunes específicos.
- Las 10 páginas prioritarias incorporan un centro de recursos con enlaces estáticos a guías y calculadoras relacionadas.
- El resultado de ISR añade límite inferior del rango y tasa efectiva estimada, conservando cuota fija, excedente, tasa marginal, ISR y neto.
- El resultado de ISR aclara que no incorpora subsidio al empleo, IMSS ni otros ajustes de nómina.
- El sitio conserva URL compartible, historial, favoritos, escenarios guardados, comparación, gráficas, copiar, compartir, exportar CSV, imprimir, modo oscuro y PWA.
- Assets actualizados a versión 4.2.0 para evitar que el navegador conserve CSS o JavaScript anterior.
- No se inventó un tipo Schema `Calculator`: se mantiene `WebApplication`, Breadcrumb, FAQ, WebSite y Organization porque son tipos válidos para esta estructura.

## Control de calidad

- 68 HTML verificados.
- 50 calculadoras.
- 66 URLs del sitemap.
- 400 FAQ visibles.
- Títulos y canónicos únicos.
- JSON-LD válido.
- Enlaces locales válidos.
- Auditorías móvil, rendimiento, publicación, funciones y simuladores aprobadas.
- `sitemap.xml` conservado sin cambios respecto a V4.1.

La indexación y posición final dependen de Google. Estas mejoras aumentan la utilidad, diferenciación y profundidad del sitio, pero no garantizan una posición concreta.
