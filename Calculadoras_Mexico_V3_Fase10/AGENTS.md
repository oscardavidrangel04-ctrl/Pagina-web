# Skills del proyecto

## frontend-design

Skill instalada en `.agents/skills/frontend-design/SKILL.md`, desde `anthropics/skills`.
Para tareas de creación o modificación de interfaces y diseño visual en este repositorio, lee ese archivo y aplica sus instrucciones dentro del alcance solicitado por el usuario. Las instrucciones y restricciones del usuario tienen prioridad.

La instalación y su verificación se documentan en `.agents/skills/INSTALLATION.md`.

## Taste Skill

Taste Skill oficial está instalada para Codex en `.agents/skills/design-taste-frontend/SKILL.md`.
Cuando el usuario solicite Taste Skill o un rediseño con sus principios, lee sus instrucciones completas y las referencias aplicables antes de implementar. Las restricciones del usuario prevalecen sobre sus patrones de landing: conserva contenido SEO, enlaces, publicidad y funcionalidades del proyecto. Mantén el CSS de la home aislado de las demás páginas.

La procedencia, versión, revisión fijada y verificación se documentan en `docs/home-taste/SKILL-INSTALLATION.md`. El kit es una dependencia de desarrollo y está excluido del build público.
