Comprobante de liquidación

Carta de pago de deuda

Datos que ayudan a documentar que una obligación fue liquidada.

Qué debe incluir

  • Nombre de acreedor y deudor.
  • Referencia del contrato o cuenta.
  • Monto y fecha de liquidación.
  • Declaración de saldo en cero.
  • Firma y datos de contacto verificables.

Conserva recibos y estados de cuenta. En créditos formales solicita la carta finiquito directamente a la institución; este contenido es informativo y no sustituye asesoría legal.

Ejemplo de solicitud a la institución

Solicito una constancia o carta finiquito del crédito identificado con la referencia [número], liquidado el [fecha]. Agradeceré que indique el nombre de las partes, el monto pagado y que el saldo pendiente es cero, junto con los medios para verificar su autenticidad.

Este texto es un ejemplo de solicitud, no una constancia de pago. Solo el acreedor puede emitir el documento que corresponda. No publiques números completos de cuenta ni datos sensibles.

Después de recibirla

Comprueba que los datos coincidan con el contrato y el último comprobante; guarda una copia junto con estados de cuenta y recibos. Si hubo una quita o reestructura, pide que el documento describa las condiciones acordadas y cómo quedó el saldo. Si aún estás organizando pagos, consulta el plan para salir de deudas.

Fuente: CONDUSEF, carta finiquito.
