# V5.3.9 — Propina Long-tail SEO

Base: V5.3.8.

## Objetivo
Hacer visibles en HTML las long-tail que ya resuelve la herramienta, sin crear páginas duplicadas ni añadir texto innecesario.

## Mejoras
- Casos rápidos visibles:
  - cómo calcular 10% de propina;
  - cómo calcular 15% de propina;
  - cómo calcular 20% de propina;
  - cuánto paga cada persona;
  - convertir propina en pesos a porcentaje;
  - calcular propina desde un total final deseado.
- Bloque “Cómo calcular propina rápido sin calculadora”.
- Diferenciación explícita entre Propina y Reparto de cuenta para reducir canibalización.
- 2 FAQs nuevas para cálculo inverso.
- FAQPage actualizado para coincidir con el contenido visible.
- No se crean nuevas URLs para variaciones con la misma intención.
- Title, H1, canonical y URL se mantienen.
