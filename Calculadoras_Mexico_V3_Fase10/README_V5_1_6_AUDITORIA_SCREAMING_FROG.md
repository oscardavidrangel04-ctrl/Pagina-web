# Calculadoras México V5.1.6 — Auditoría Screaming Frog

Fecha: 15 de agosto de 2026.

Esta versión parte de V5.1.5 y aplica la auditoría on-page reunida con Screaming Frog y Search Console.

## Cambios principales
- 50 titles revisados para priorizar intención y reducir truncamiento.
- 50 H1 alineados con la búsqueda principal de cada calculadora.
- Meta descriptions únicas y específicas; se eliminó el boilerplate repetitivo en las páginas pendientes.
- H2 genéricos contextualizados por calculadora para mejorar el outline y la escaneabilidad.
- El encabezado global del footer `Calculadoras México` pasa de H2 a H3 en las páginas trabajadas.
- El bloque semántico de V5.1.5 deja de mostrar una lista explícita de consultas y usa una frase natural.
- Instrucciones y advertencias comunes se acortaron para facilitar la lectura.
- Se reforzó contenido útil en simuladores, índice de artículos y ocho guías con poco contenido.
- Se preservaron URLs, canonicals, robots.txt, scripts de calculadoras, fórmulas y monetización. El sitemap conserva las mismas 66 URLs y actualiza `lastmod` solo en las páginas modificadas.
- Se conserva la canonicalización correcta de `/index.html` y de filtros `?categoria=`.

## Decisiones conscientes
- No se rellena con texto las páginas legales/contacto solo para superar un umbral de palabras.
- No se añadió `meta keywords`.
- No se añadieron ni eliminaron URLs del sitemap; solo se actualizó `lastmod` de forma coherente con los cambios reales.
