Qué puedes calcular con esta calculadora de bono

La calculadora de bono obtiene el valor de un bono a partir de dos datos de entrada: el salario base o monto base y el porcentaje acordado. Después muestra el bono bruto y el total bruto de referencia.

Es útil para revisar un bono por desempeño, una bonificación porcentual o bonos y comisiones pactados como porcentaje. No sustituye un recibo de nómina: sirve para comprobar el resultado matemático antes de revisar la forma en que la empresa lo paga.

Cómo usar la calculadora de bono

  1. Escribe el salario base o el importe sobre el que se aplicará el bono.
  2. Captura el porcentaje indicado en tu contrato, política interna o acuerdo de pago.
  3. Pulsa Calcular y revisa el valor de un bono y el total bruto.
  4. Si quieres comparar opciones, cambia solo un dato del formulario y vuelve a calcular.

Antes de usar el resultado, comprueba que ambos datos usen el mismo periodo. Por ejemplo, no combines un salario mensual con un porcentaje que se aplica a una venta semanal salvo que esa sea la regla acordada.

Qué debes considerar al calcular un bono

La herramienta resuelve el porcentaje y la suma. El pago real puede incluir condiciones adicionales: metas, asistencia, fecha de pago, topes, proporción por días trabajados o aprobación de recursos humanos. Revisa esas condiciones antes de tomar el resultado como una cifra definitiva.

Cómo se calcula un bono por porcentaje

Para calcular bono, multiplica el salario base por el porcentaje del bono. Si el salario base es de $20,000 y el bono es de 10%, el valor del bono es $2,000. Al sumar ambas cantidades, el total bruto es $22,000.

Fórmula del bono

Bono bruto = salario base × (porcentaje ÷ 100). Después, total bruto = salario base + bono bruto. La fórmula funciona igual si la base es un sueldo, una comisión, una venta o cualquier otra cantidad definida por escrito.

Ejemplos de cálculo

Salario base Bono Valor del bono Total bruto
$12,000 5% $600 $12,600
$20,000 10% $2,000 $22,000
$28,000 15% $4,200 $32,200

Los ejemplos muestran una operación matemática antes de deducciones. No representan una nómina ni un pago garantizado.

¿De cuánto es el bono?

No existe un monto único: depende de la base y del porcentaje acordados, además de las condiciones para obtenerlo. Con una base de $20,000 y un bono de 10%, el bono bruto es $2,000. La calculadora comprueba esa operación; no determina por sí sola tu derecho al pago.

Si la base son ventas, el total no es tu sueldo

Con ventas de $50,000 y una comisión de 5%, la bonificación calculada es $2,500. La suma de base más bono sería $52,500, pero no representa tu salario ni el importe que deben depositarte: incluye las ventas utilizadas como base.

Interpreta el total como sueldo más bono únicamente cuando la base sea el sueldo correspondiente y ambos conceptos deban sumarse según el acuerdo. Para una comisión sobre ventas, toma el monto de la bonificación y revisa por separado cualquier sueldo fijo.

Qué puede cambiar el pago real

  • Base del bono: puede ser salario base, sueldo bruto, ventas, utilidad o una meta específica.
  • Reglas de pago: algunas empresas condicionan los bonos y comisiones a metas, asistencia o permanencia.
  • Conceptos distintos: vales de despensa, viáticos y otros beneficios no necesariamente se calculan con esta fórmula.
  • Periodo: confirma si el porcentaje se aplica por semana, quincena, mes o año.
Referencia: Ley Federal del Trabajo, Cámara de Diputados. Consulta tus condiciones de trabajo y el recibo de nómina para determinar el pago aplicable.

¿Cómo saber qué porcentaje representa un bono?

Si ya conoces el importe del bono, divide el bono entre la base y multiplica por 100. Por ejemplo, $1,500 ÷ $15,000 × 100 = 10%. Puedes capturar ese porcentaje arriba para comprobar el importe.

Para comparar una oferta con otra, usa el mismo periodo y distingue un bono único de uno recurrente. Un bono de $1,500 una vez al año no equivale a recibir $1,500 cada mes. Para revisar un pago después de deducciones, consulta la calculadora de salario neto con los conceptos y el periodo correspondientes.

Cálculo de bono de productividad: ejemplo con metas

Primero revisa qué base y qué regla reconoce tu plan de incentivos. Si establece un bono del 8% sobre $18,000 al cumplir la meta completa, el bono bruto es $1,440 y la suma con esa base es $19,440.

Si el plan además paga proporcionalmente al cumplimiento y alcanzaste el 75% de la meta, el porcentaje efectivo sería 8% × 75% = 6%: captura $18,000 y 6 para obtener $1,080. Solo aplica esa proporción si está prevista en el plan; algunos bonos tienen umbrales o cantidades fijas.

La calculadora admite bonos laborales definidos como porcentaje. El precio o rendimiento de un bono financiero y el bono de pensión del ISSSTE requieren métodos distintos. Para revisar la integración de un incentivo laboral, consulta bonos y salario base de cotización.

Preguntas frecuentes

¿Cómo se calcula un bono de productividad?

Primero verifica la base y el porcentaje reconocidos por tu empresa. Si la base es $15,000 y el bono corresponde al 10%, el importe bruto es $1,500. La calculadora no decide si cumpliste una meta.

¿Cómo calculo qué porcentaje representa mi bono?

Divide el bono entre su base y multiplica por 100. Un bono de $1,500 sobre $15,000 representa 10%; sobre $30,000 representa 5%.

¿El bono se calcula sobre ventas o sobre sueldo?

Depende de las condiciones del bono. Captura la base realmente acordada. Si es venta, la fila base más bono no equivale a tu sueldo de nómina.

¿El bono mostrado ya está libre de impuestos?

No. Es un importe bruto aritmético. Para comprobar el depósito, revisa las percepciones y deducciones del recibo y utiliza salario neto con descuentos conocidos.

¿Un bono es lo mismo que aguinaldo?

No. Este cálculo aplica un porcentaje a una base. El aguinaldo utiliza días de salario y tiempo trabajado; consulta la calculadora de aguinaldo.

Bono bruto, bono neto e ISR: cómo revisar el recibo

Esta calculadora muestra el bono bruto. En una nómina, un bono gravado normalmente se suma a las demás percepciones gravadas del periodo y la retención se obtiene sobre ese total; por eso no es fiable aplicar un porcentaje fijo de ISR únicamente al bono.

  1. Identifica tu sueldo bruto y el importe bruto del bono.
  2. Revisa si el bono tiene una parte exenta o una regla específica en tu recibo.
  3. Compara la nómina con y sin bono; la diferencia de retención aproxima el efecto fiscal.

El IMSS y otras deducciones pueden cambiar el neto final según el tipo de percepción y tu situación. Para una estimación de sueldo después de descuentos, abre la calculadora de salario neto.

Datos que conviene revisar antes de calcular

Confirma si el porcentaje se aplica al salario mensual, quincenal, diario o a otra base. También revisa metas, asistencia, proporcionalidad por días trabajados, topes y fecha de pago. El contrato, la política de bonos y el recibo de nómina determinan el importe exigible.
