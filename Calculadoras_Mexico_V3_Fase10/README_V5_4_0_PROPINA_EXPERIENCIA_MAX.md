# V5.4.0 — Propina Experiencia MAX

Base: V5.3.9.

## Mejoras principales
- Recalculo automático en vivo mientras el usuario cambia datos válidos.
- Se conserva el botón Calcular por claridad y accesibilidad.
- Opción “Mi cuenta ya incluye propina o cargo por servicio”.
- Campo para indicar el cargo ya incluido.
- Cálculo del porcentaje equivalente de ese cargo.
- El cargo incluido se separa de la propina adicional para evitar sumarlo dos veces.
- El modo “Total final deseado” ahora considera el cargo ya incluido.
- Nueva interpretación personalizada del resultado.
- Nueva comprobación matemática del porcentaje mostrado.
- Copiar/compartir conserva cuenta base, cargo incluido, propina adicional, total y reparto.
- No se modifica title, H1, URL ni canonical.
- No se añaden bloques grandes de contenido SEO.
