# Calculadoras México V5.2.8 — Unificada: 5 Clusters Premium + ISR Senior SEO/GEO

Fecha: 17 de agosto de 2026.

## Base unificada
Esta versión toma como base **V5.2.7 — 5 Clusters Premium SEO** y conserva sus mejoras en:
- ISR / sueldo / nómina
- Finiquito / liquidación
- Aguinaldo
- Sueldo bruto / neto
- Vacaciones / prima vacacional
- Hub `/calculadoras.html`, home y sitemap con `lastmod` de las páginas realmente modificadas.

Encima de esa base integra **V5.2.7 — ISR Senior SEO + GEO** para `/calculadoras/isr.html`.

## ISR integrado
- Search intent transaccional + informacional.
- Keyword principal: `calculadora ISR 2026 México`.
- Cobertura mensual, quincenal y semanal sin crear URLs canibalizadas.
- Respuesta directa y fórmula cerca de la parte superior.
- Ejemplos y explicación de tasa marginal, tasa efectiva y resultado después de ISR.
- Fuentes y metodología visibles.
- Alcance y limitaciones explícitos.
- FAQs visibles + datos estructurados correspondientes.
- WebPage + WebApplication + BreadcrumbList.
- Enlaces internos a salario neto, salario bruto, pago quincenal y guías educativas.
- Presets de importes y ayuda contextual del periodo mediante `assets/js/isr-seo-ux.js`.

## Qué se preservó de 5 Clusters Premium
- Las 10 páginas adicionales del cluster mantienen sus titles, metas, H1, bloques de navegación contextual y respuestas rápidas.
- Aguinaldo conserva su versión avanzada y estabilidad SEO.
- `/calculadoras.html` mantiene sus accesos a los cinco clusters prioritarios.
- `index.html` mantiene la arquitectura de hub y enlaces internos del paquete de clusters.
- `sitemap.xml` conserva los `lastmod` de las páginas del cluster actualizadas el 17-08-2026.
- `assets/css/styles.css` mantiene los estilos de los bloques de cluster Premium.

## Decisión de merge
No se sobrescribieron `index.html`, `calculadoras.html`, `sitemap.xml` ni las páginas de los otros clusters con las copias del paquete ISR Senior, porque esas copias partían de una base anterior y habrían eliminado mejoras más recientes del paquete de 5 Clusters.

## Versionado de caché
En ISR se usa `styles.css?v=5.2.8` e `isr-seo-ux.js?v=5.2.8` para facilitar la actualización visual/funcional tras el despliegue.
